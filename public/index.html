Generation limits

Tool budgets are optional and off when blank. A round is one response that requests tools. The final text answer does not count. At a budget, completed work stays saved and the model receives a final-answer request. Argument, context, output, resource, and time limits still apply.

Unsupported provider controls are hidden. Each response retains its own settings.

Tools

Dictation

Dictation is not implemented. This button opens settings only. Common Chat does not record, transcribe, or send microphone audio.

MCP

Model Context Protocol (MCP) integration is not implemented. No MCP servers are connected. No MCP tools are granted to a model.

Appearance

Conversation history

Import JSON, JSONL, or ZIP exports. Repeated imports create separate conversations.

Exports contain messages, branches, and supported attachments. They exclude credentials, connection keys, workspace files, and browser drafts.

Server storage

This version uses one shared owner account. For a full backup, stop the server and use the supported backup procedure. Keep master.key with the database, attachments, and workspace revisions.

About

Common Chat 0.2 preview.

A standalone implementation with theme tokens adapted from llama.cpp. An administrator applies updates while the server is idle.

Composer

Enter sends a message. Shift+Enter adds a line. The model icon selects a model. The paperclip opens Upload and Tools. On supported connections, native tools are available automatically. Execution needs a ready runner. Availability is checked before each turn. Manual review and Run stay separate. The microphone opens the inactive Dictation settings.

Drafts are saved only in this browser. History is stored on this server. Review model output before use. Sign out clears drafts for this server in the current browser.

Connections and uploads

The chat server reaches the model endpoint. The base URL usually ends in /v1. API keys stay on the server. Choose capabilities only when the endpoint and model support them.

Attach at most ten files per message. Each file must not exceed 10 MiB. Audio/video need explicit compatible input protocols and server inspection.

Files and recovery

Workspace files are separate from message attachments. File and code editor buffers remain in this page. Save or copy those edits before reloading. Conversation exports do not replace a full offline backup.

A response continues if this browser disconnects. A server crash interrupts generation. Saved partial output remains, but generation does not resume automatically.
